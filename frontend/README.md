# ResultBoard frontend

Next.js App Router client for the Student Result & Leaderboard System. See the [project README](../README.md) for complete setup, backend configuration, demo accounts, and feature details.

Run locally:

```sh
npm install
npm run dev
```

By default, the frontend uses `http://localhost:5000/api`. Set `NEXT_PUBLIC_API_URL` in `frontend/.env.local` to point it at a different backend. `npm run build` creates the production build and `npm start` serves it.
